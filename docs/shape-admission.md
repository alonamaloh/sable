# The shape × stage-gate admission table

Which shapes each consuming stage admits, probed directly rather than through the parser.
Generated by `compiler/src/shape_admission.rs`; rewrite it with `SABLE_BLESS=1 cargo test
--lib shape_admission`.

`docs/type-matrix.md` answers what a source program may write where. This table answers
what a stage would accept if a shape reached it, which is the question a change to the
type representation can silently move. A cell is `yes` when the gate accepted the shape
and the gate's machine-matchable name when it refused. A stage that is a traversal rather
than a gate — substitution, visibility collection, the present case of an option —
records what it produced, so a lost recursive arm moves a cell too.

Every stage is asked about every shape: the grammar is one recursive type, so there is no
shape a stage cannot be handed. A cell that moves is either a refusal that was deleted or
an admission that was widened, and both need a reason.
